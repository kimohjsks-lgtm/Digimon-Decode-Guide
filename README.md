# Digimon Decode Guide Tracker

Interactive checklist for **Digimon World Re:Digitize Decode (3DS)** — town recruits, sub-events, and secrets.

Inspired by [DW1 Recruitment Helper](https://fliegenfuerst.github.io/dw1/recruitment/).

## Features

- 116 prosperity-related sub-events with conditions, steps, and rewards
- Filter by **All / Recruits / Events / Secrets**
- Group by **location** or **name A–Z**
- Search by name / text
- Hide completed or hide unavailable (prereqs / prosperity)
- Progress saved in **cookies** (survives refresh)
- Reset progress button

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
# Python
python -m http.server 8080

# Node
npx --yes serve .
```

Then visit `http://localhost:8080`.

## GitHub Pages

Enable Pages on this repo (Deploy from branch → `/` root). Site will be available at your Pages URL.
